# ByCrawl n8n node agent guide

This is the ByCrawl community node package for n8n. `nodes/ByCrawl/` defines resources, operations and execution; `credentials/` owns API credentials; `dist/` is generated by TypeScript and the icon build.

## Development and validation

Use npm with the committed `package-lock.json`; use Node 22 for local/CI checks. Run `npm ci`, then `npm run check:pr` (lint, build, compiled-node contract and pagination tests). These tests exercise the routing callback with fixtures; they do not establish how every n8n runtime version unwraps provider envelopes. For changed operations, verify parameters and response/error handling against the ByCrawl gateway and exercise the operation in a task-owned n8n instance when runtime validation is required.

Keep n8n resource/operation identifiers compatible with saved workflows, and align UI defaults, required fields and execute-time parameter mapping. Update README capability descriptions alongside supported operations. Never embed API keys in node defaults, examples or test artifacts.

Locate the gateway/MCP checkout by its remote before cross-repo changes. Package version changes, npm publication and release tags are separate from ordinary PR work. Inspect current workflows and release state before a release; do not assume another local checkout's workflow has been merged.
